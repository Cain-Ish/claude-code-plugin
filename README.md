# second-brain v2 (in development)

A Claude Code plugin that keeps a project map per repo — what the lead developer, PM and designer know: structure,
conventions, goals, and past decisions with their reasons — and gives Claude the part a task needs, at the lowest
token cost.

**Status: concept phase.** Nothing here is installable yet. The design is being decided step by step, each decision
checked when it is made.

- Brief: [docs/v2/00-charter.md](docs/v2/00-charter.md)
- How decisions are made: [docs/v2/01-process.md](docs/v2/01-process.md)
- Decision ledger: [docs/v2/DECISIONS.md](docs/v2/DECISIONS.md)
- Progress: the [v2 map issue #115](https://github.com/Cain-Ish/claude-code-plugin/issues/115) and the "v2 concept"
  milestone. Work runs one step at a time with `/v2-step` in a checkout of this branch.

**Looking for the working plugin?** v1 (0.57.1) is on [`main`](https://github.com/Cain-Ish/claude-code-plugin) and
frozen at the [`v1-final`](https://github.com/Cain-Ish/claude-code-plugin/releases/tag/v1-final) release.
