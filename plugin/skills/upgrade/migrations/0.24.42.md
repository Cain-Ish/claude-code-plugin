# Migration to 0.24.42

## What changed

The 5 vendored obra/superpowers skills (brainstorming, systematic-debugging,
test-driven-development, verification-before-completion, writing-plans) were
removed from this plugin (R6 de-vendor). The plugin's workflow prose now
references the upstream `superpowers:*` skill names.

## Action / idempotent check

If the `superpowers` plugin is not installed, install it from the official
marketplace (>= 5.1.0) to keep the discipline skills available:
`claude plugin install superpowers@claude-plugins-official`. Idempotent check:
`ls -d ~/.claude/plugins/cache/*/superpowers/*/` succeeds → nothing to do.
The second-brain functions without it; this only affects the five skills.
