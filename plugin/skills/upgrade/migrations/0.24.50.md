# Migration to 0.24.50

## What changed

Deep-review correctness batch + the start of the test-quality fix:
- **P4 FORGET**: `dream-snapshot` used `cp -r`, resetting every staged page's
  mtime to "now"; `dream-accept` rsynced those onto live, re-arming the FORGET
  age-gate corpus-wide so nothing could ever age into a candidate (silently
  neutering the 0.24.47 recency fix). Now `cp -rp` preserves mtimes.
- **P8 episodic ranking**: text-mode similarity was a constant 0.5 (the AND-loop
  forced it) and results were sliced UNSORTED → arbitrary truncation. Now scores
  vary by term-frequency density and sort before slicing.
- **P7**: the per-prompt "Past sessions" hint used mode:'vector' with no
  fallback — silently empty on any box without the embedding model. Now
  mode:'both' (degrades to text, which now ranks meaningfully).
- **P9**: episodic index / access-counts / dream status.json were written
  non-atomically (a crash mid-write corrupted them, reader fails open to empty).
  Now tmp+rename via a shared atomicWriteJson.
- **Test quality**: a real-YAML-parser oracle (test-oracle.ts) replaces the
  tautological regex re-reads in the graph/reindex/validate tests (they asserted
  the implementation's own output via the same reader that masked the bug).

## Action / idempotent check

No user action. The FORGET fix takes effect on the next dream cycle; nothing to
migrate. (Optional: `/second-brain:reindex` to refresh, but not required.)
