# Migration to 0.25.0

## What changed

**Autonomy: gated auto-accept.** Dreams can now self-apply to the live wiki
unattended, behind a new `auto_accept` config key (default `"off"` — the
marketplace-safe default keeps the original "nothing reaches live without a
human accept" guarantee). The three-tier consent ladder
(`auto_improve` / `auto_maintain` / `auto_accept`, all default off) is now
documented and presented by `/second-brain:setup`. When enabled:
- `auto_accept: "safe"` applies only a dream proposing no FORGET-archives and
  no deletions (pure reversible consolidation);
- `auto_accept: "all"` applies any completed dream.
Every auto-accept BACKS UP the live wiki first (a dated tarball under
`~/.second-brain/`), on top of FORGET already being a reversible move (never a
delete). The headless path only auto-accepts when `auto_maintain` is also on,
so full unattended operation requires both consents.

## Action / idempotent check

No action required — default behavior is unchanged (`auto_accept` absent →
`"off"` → manual review, exactly as before). To opt into self-driving, set
`"auto_accept": "safe"` (recommended) or `"all"` in
`~/.second-brain/config.json`, and `"auto_maintain": true` for unattended
headless dreams (note: that enables a headless `claude -p` that reads your
OAuth creds with the network up — enable consciously). Idempotent check:
`jq -r '.auto_accept // "off"' ~/.second-brain/config.json`.
