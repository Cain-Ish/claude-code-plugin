# 0.33.19 — migration notes (P1 capture self-heal hardening)

Two behavioral fixes from the live 0.33.18 upgrade. Both are active the moment the new code loads;
the one real action is **re-running the shim-aware `--ensure`** so any stale, shim-less scheduler
left by an older version is repaired.

## What changed

- **Shim-aware `sb_timer_installed`.** A registered scheduler whose shim (`~/.second-brain/bin/
  sb-extract-drain.sh`) is missing — e.g. a stale task from an old version whose shim was GC'd — now
  reads as not-installed, so `--ensure` / the session-load self-heal regenerate it instead of leaving
  the scheduler execing a non-existent shim and failing silently every fire.
- **In-session floor path normalization.** The in-session deterministic floor now forward-slash-
  normalizes Windows paths (matching the drainer twin); no data migration — only newly-written
  decisions were ever backslash-form, and they remain valid.

## Action / idempotent check

Repair a possibly-stale scheduler by re-running the now shim-aware `--ensure`. On a healthy install
it no-ops (`already installed`); on a shim-less/absent one it re-applies and regenerates the shim.

**Skip if `SB_DISABLE_AUTO_TIMER=1`:**

```bash
if [ "${SB_DISABLE_AUTO_TIMER:-0}" = "1" ]; then
  echo "drainer scheduler: skipped (SB_DISABLE_AUTO_TIMER=1)"
else
  bash "${CLAUDE_PLUGIN_ROOT}/scripts/install-extract-timer.sh" --ensure
fi
```

Idempotent check: after the run, the shim exists and a second `--ensure` prints `already installed`:

```bash
test -f ~/.second-brain/bin/sb-extract-drain.sh && echo "shim OK" || echo "shim MISSING"
```
