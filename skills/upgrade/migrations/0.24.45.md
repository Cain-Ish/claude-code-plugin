# Migration to 0.24.45

## What changed

The daily Opus spending CAP was removed across both plugins (user decision,
2026-06-11): premium-tier models change over releases (Opus today, Fable and
future top-tier models next), so a hardcoded dollar limit keyed to one model
aged badly. The shared ledger (`~/.second-brain/opus-budget.json`) is now
INFORMATIONAL — banners and routing summaries report what premium dispatches
cost today; nothing blocks. `COST_ROUTER_OPUS_CAP_USD` and
`SB_PERSONA_DAILY_BUDGET` no longer gate anything.

## Action / idempotent check

Only relevant if you exported `COST_ROUTER_OPUS_CAP_USD` (or
`SB_PERSONA_DAILY_BUDGET`) expecting enforcement: that protection is gone —
remove the env vars (they are inert) and watch the SessionStart banner's
"premium-model spend today" line instead. Idempotent check:
`bash <plugin>/cost-router/scripts/opus-budget.sh over` exits 1 with a
"removed" notice → migrated. Old ledgers with a `cap_usd` key are read
fine (the key is ignored, dropped on next write).
