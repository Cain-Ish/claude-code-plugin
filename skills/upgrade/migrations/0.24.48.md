# Migration to 0.24.48

## What changed

Node-shape convergence — lint, the maintainer, and the dream now keep every
node in the SAME canonical shape:
- `knowledge_validate` gained two issue types. `incomplete_frontmatter` +
  `patch_frontmatter` autofix fills ONLY absent required fields (title,
  description, type, created, updated, tags, related) — never overwrites a
  value, never invents `created`/`updated` from "today" (derives from a body
  `**Date**:` line, a date-prefixed slug, or file mtime). `related_drift` is a
  WARN-only check that reports when a page's `related:` disagrees with the
  current edge graph (the projector remains the sole writer — no autofix).
- The dream now runs the maintainer's exact shaper (`knowledge_validate`
  autofix via the new `sb_validate_wiki` helper) over its STAGING dir at
  `dream_accept`, BEFORE merging onto live — so dream-authored pages arrive in
  canonical shape, not relying on the post-merge reindex to clean them.
- Fixed `extractYamlValue`: `description: ""` parsed to a stray `"` (broke MOC
  descriptions + reindex idempotency once a page carried an empty description).

## Action / idempotent check

Run ONE consolidation pass to patch any incomplete pages to canonical shape:

`/second-brain:reindex`  (or `/second-brain:maintain`)

The patch is idempotent and uncapped; it fills only absent fields and never
re-dates a page. Idempotent check: a second reindex reports 0
`incomplete_frontmatter`/`malformed_frontmatter` issues and 0 pages updated.
No data is deleted — only absent required fields are added.
