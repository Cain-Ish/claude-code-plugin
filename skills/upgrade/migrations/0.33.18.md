# 0.33.18 — migration notes (P1 autonomous capture loop)

Ships the fully-autonomous capture loop. Most of P1 is **behavioral** (deterministic floor in
the Stop hook + drainer; self-healing session-load banner) and needs no migration — it is active
the moment the new code loads. The ONE real precondition is the out-of-band drainer **scheduler**:
it must be installed for the timer-driven capture to run, and P1's mandate is that this happen with
no manual step.

## What changed

- **Deterministic capture floor.** Under OAuth with no extractor backend, both the in-session Stop
  hook AND the out-of-band drainer now write a real files-changed delta to PROJECT.md instead of
  capturing nothing. The drainer's floor is **last-resort** — it fires only after the LLM has failed
  `SB_DRAIN_MAX_FAILS` times, so LLM enrichment is preserved until then. Opt out: `SB_DRAIN_FLOOR=off`.
- **Drainer scheduler installed by default + self-healing.** `install-extract-timer.sh` gained an
  idempotent `--ensure` mode; setup and the OAuth session-load banner now install the **hardened,
  no-credentials** unit automatically. The credentialed `--oauth` variant stays a separate, explicit
  consent. Opt out everywhere: `SB_DISABLE_AUTO_TIMER=1`.
- **Windows path fix.** Decisions citing `C:\…` paths were corrupted in PROJECT.md (`awk -v`
  escape-processing turned `\t` into a TAB). Fixed for the floor AND the LLM path. No data migration —
  only newly-written decisions were ever affected.

## Action / idempotent check

Install the out-of-band drainer scheduler so timer-driven capture actually runs. This is the **one
host-state change** in this release: a single per-user scheduler entry (systemd user timer / launchd
LaunchAgent / Windows Scheduled Task), hardened and credential-free. `--ensure` is idempotent — it
no-ops if already installed.

**Skip entirely if `SB_DISABLE_AUTO_TIMER=1`** (the operator opted out of autonomous capture):

```bash
if [ "${SB_DISABLE_AUTO_TIMER:-0}" = "1" ]; then
  echo "drainer scheduler: skipped (SB_DISABLE_AUTO_TIMER=1)"
else
  bash "${CLAUDE_PLUGIN_ROOT}/scripts/install-extract-timer.sh" --ensure
fi
```

Idempotent check: a second `--ensure` prints `already installed: …` and changes nothing. On Linux it
also PRINTS a `loginctl enable-linger` line for the operator to run (a separate host-state change the
script never runs itself). The credentialed headless-LLM path is NOT enabled here — that still requires
an explicit `--apply --oauth` plus `auto_maintain: true`.
