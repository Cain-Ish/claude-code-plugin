# 0.53.0 — the buddy becomes a two-way, animated capybara

One step if you use the buddy statusline; nothing otherwise.

## If the buddy statusline is installed: re-run install once

```
/second-brain:buddy install        # or: sb buddy install
```

Already done? `grep -q '"refreshInterval"' ~/.claude/settings.json && grep -q '"react": true'
~/.second-brain/buddy.json` — both succeed after the re-install; nothing to do then. The buddy also
tells you itself: a 0.51.0 or 0.52.0 install gets a one-time "run /second-brain:buddy install" line.

Then restart Claude Code. It adds `"refreshInterval": 1` to your `statusLine` (the animation tick —
Claude Code re-runs the statusline once a second while idle), rewrites the shim at
`~/.second-brain/bin/buddy-statusline.sh` (newest-version pick without `ls`/`sort`, sources the
renderer), and takes a settings backup first. Your chained statusline stays line 1; its output is
now cached for 5 s per session so the per-second tick does not re-run it. Without this step the
capybara still renders but only moves when something happens.

## What changed

- **One capybara, no roll.** The species/rarity/eye/hat/shiny roll from your Claude account id is
  gone; the buddy is Kapi the capybara — a name you had from the roll is not kept (rename with
  `sb buddy name <x>`). `sb buddy` drops the old `identity` block from `~/.second-brain/buddy.json`;
  `--rehatch` is gone.
- **Animated like the native `/buddy`.** Three frames, the idle cycle with a blink, excited for 10 s
  after a new line; `(·oo·)` on narrow terminals.
- **Two-way — only after this re-install** (installing is the consent; `buddy.json` gets
  `react: true`). Each prompt then carries one `[buddy: Kapi]` line (~80 tokens) and Claude ends its
  turn with the new `buddy_react` MCP tool — one extra tool call per turn — and the bubble shows
  what Claude says to you as "Claude: …". If Claude Code asks to allow `buddy_react`, choose
  "don't ask again". `SB_BUDDY_REACT=off` keeps the display and drops the line; `SB_BUDDY=off`
  turns the buddy off entirely.
- **Install is safer.** Re-install and uninstall read your chained statusline back from
  `settings.json` itself, never from `buddy.json`; your `padding` and a `refreshInterval` you set
  yourself are kept.
