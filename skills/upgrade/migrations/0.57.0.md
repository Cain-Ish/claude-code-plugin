# 0.57.0 — guards hold under load, capture keeps every decision

Restart Claude Code sessions that are still open. Everything else runs on its own; the last section
lists what to look at once.

## What changed

- **Learned habits are no longer trusted rules.** A persona signal seen in two different sessions is
  stored in `~/.second-brain/persona-learned.md` and shown at session start inside the untrusted-data
  frame. `USER.md` now holds only pins you made yourself (the `pin_to_user` tool, `sb pin user`). Graduation needs two
  different session ids, and text that reads like an instruction is refused. On the first session start
  after the upgrade, signals that had graduated into `USER.md` earlier are moved to `persona-learned.md`
  automatically (marker `.persona-learned-migrated`).
- **PROJECT.md and USER.md are locked while written.** The Stop and PreCompact merges, the drainer,
  `pin_to_project`, `pin_to_user` and `archive_to_wiki` share one lock file next to the target and write
  through a temp file plus rename. A merge that finds the lock busy (`SB_ARCHIVE_LOCK_WAIT_S`, 5 s;
  PostCompact waits up to 20 s) retries later. A PROJECT.md that cannot be read, starts with a UTF-16
  byte-order mark, or changes while a merge runs is left untouched instead of being rebuilt.
- **Missing section headings are re-created** instead of silently dropping new decisions.
- **Guards:** `rm` with split or long flags, `/bin/rm -rf`, `\rm -rf`, `bash -c 'rm -rf …'`,
  `git push origin +main`, `git push -fu origin main` now ask; plain `rm -f file` does not. The PowerShell
  tool is guarded: Bash-syntax rules apply to it, and `Remove-Item -Recurse -Force` (also `ri`, `rd`,
  `del`, quoted inside `pwsh -c "…"`) asks. Edit and MultiEdit of `USER.md`, `persona-card.md` and the
  rules file ask, like Write; `PROJECT.md` does not. Sending a credential file toward the network asks in
  more forms: piped or substituted readers, `scp`/`rsync`/`tar`, PowerShell `gc`/`-InFile`/`ReadAllText`,
  `Start-BitsTransfer`, `Send-MailMessage`, in any letter case.
- **hook-timer** no longer kills heavy hooks (Stop, PreCompact, session start, per-prompt context): an
  over-budget run finishes and leaves a `"timeout":true` row plus an `after_timeout` row with its real
  exit code. Guard hooks (budget under 10 s) are cleaned up, child processes included, only after Claude
  Code has stopped waiting; a guard's own decision is never changed.
- **Dream accept keeps your edits**: a failed copy without rsync keeps the saved pages, restored pages are
  no longer deleted by the next accept, and FORGET scoring is about 50x faster.
- **MCP tools** (`knowledge_fetch`, `knowledge_search`, `episodic_read`, `episodic_search`,
  `dream_status`, `persona_stats`) return stored text inside the untrusted-data frame.
- **persona_think / `/?`** need `ANTHROPIC_API_KEY` (or `SB_FORCE_CLI=1`) inside a session; under a subscription
  login they refuse and say so instead of hanging.

## Removed

- The "dream consolidation suggested" banner and its session counter (`.session-count`,
  `SB_DREAM_CADENCE`); `dream-autostage` still nudges.
- The raw `projects.jsonl` line at session start.

## Look at once

1. **Restart open sessions.** A 0.56 session writes PROJECT.md without the lock until it restarts.
2. **Re-run the timer installer** if you use the scheduled drainer:
   `bash "$CLAUDE_PLUGIN_ROOT/scripts/install-extract-timer.sh" --apply` (add `--oauth` if installed
   that way). `--ensure` now checks the timer is really enabled, but the new launcher quoting and the
   BRAIN_DIR / CLAUDE_CONFIG_DIR forwarding only reach an existing install through `--apply`.
3. **Persona graduation starts over.** Stored evidence with session `unknown` no longer counts.
4. **Stray project folders.** Earlier versions wrote last-resort captures to a rewritten folder name
   (`projects/mono-api/` for `Mono__Api`). Merge their bullets into the real project by hand if you want
   them, then delete the folder.
